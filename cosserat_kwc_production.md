# 1. Scope

This document describes the 2D solver of the repository and the configuration every production run uses. Since 15 November 2026 production is the **v2** solver. It has two set-ups: the default (quasi-static lattice rotation) and **`OLD=1`** (rotational inertia $j=0.01$ µm², $\theta$ integrated by Newmark), which share every other part of the solver and every other parameter, the Cosserat multiplier included (Section 15).

| File | Role |
|---|---|
| `cosserat_kwc.edp` | base solver and single hand-edited source; not run by the scripts (the self-tests use it) |
| `cosserat_kwc_v2.edp` | production solver, generated from the base solver by exact text patches (`v2/make_v2.py`) |
| `cosserat_kwc_mpi.edp`, `cosserat_kwc_v2_mpi.edp` | the 16-rank PETSc versions, generated by `mpi/make_mpi.py` |
| `kwc2d.so` (`plugin/kwc2d.cpp`, `plugin/dual.hpp`) | element map with exact derivatives by forward-mode automatic differentiation; direct assembly of the tangent matrix |

`plugin/build_plugin.sh` (called by `run.sh` and the submit scripts) builds the plugin and regenerates the three generated files whenever a source is newer. Never edit a generated file.

**The two set-ups** differ only in the micro-inertia $j$ and therefore in how $\theta$ is integrated in time (details in the sections named):

| | default | `OLD=1` (or `INERTIA=1`) | Section |
|---|---|---|---|
| micro-inertia $j$ | 0 (lattice rotation quasi-static) | 0.01 µm² | 4 |
| $\theta$ in time | quasi-static (no $\theta$ mass) | Newmark average acceleration, like $u$ ($\rho j\ddot\theta$ in the residual, $c_0\rho j M$ in the tangent, $KE_\theta$ in the audit) | 4, 6.3 |

Everything else is the same in both, including the Cosserat constraint by a multiplier per element with the augmentation $\mu_c=754$ GPa (Section 3.8), the merit and convergence test with the constraint residual, and the FGMRES/Schur linear solve: phase field, grain-boundary spin, plasticity, densities, heat, loading, $\delta=5\times10^{-4}$, the primal–dual KWC tangent, the direct assembly, the exact slip law and every safeguard, including the local acceptance test and the rotation-branch guard. In this document "v2" means the default set-up where the two differ. Every value below is the v2 default that `tag.sh` passes (the list `PHYS`) or a constant of the solver; the `OLD=1` value is given where it differs.

The production study is the ladder `submit_ladder.sh`: plate angles 0°, 45°, 90° and plate speeds 25, 50, 100, 150, 250, 400 m/s, each up to 30 ns.

**Run tag.** `a<ANGLE>_up<speed>ms[_dt<DT>]_v2[_<RUNTAG>][_serial]`, for example `a0_up400ms_v2`; `OLD=1` runs end in `_j` instead of `_v2`. Folders ending in `_old` are runs of the former `OLD=1` (Cosserat penalty, μ_c 75.4) and folders without a suffix runs of the base solver from before 15 November; the scripts resume neither. The physics behind the 8 November tag `pistM3v2GRcVQ3_gc_ne_pm1e-2_es1_mpi_a0_up400ms` is built into both set-ups:

**Conventions.** Units are µm, ns, GPa and K. One Pa·s equals one GPa·ns, and a density of 1 code unit is 10³ kg/m³. The problem is 2D plane strain on a 10 × 10 µm reference domain Ω with 8 grains (`mesh.msh`: 58,391 triangles, 29,399 nodes; grain angles in `grain_angles_rad.txt`).

**Launch.** `bash submit_ladder.sh` (all angles and speeds), or `ANGLE=0 ARRAY=5 bash submit_speeds.sh` for one run (a0, 400 m/s); `OLD=1` in front for the set-up with rotational inertia. # 2. Unknowns and kinematics

| Symbol | Meaning | Discrete type |
|---|---|---|
| $u$ | displacement | P2 field |
| $\theta$ | Cosserat (lattice) rotation, from the grain reference orientation | P1 field |
| $\phi$ | KWC order parameter, 1 in grains, $<1$ in boundary cores | P1 field |
| $T$ | temperature | P1 field |
| $\lambda$ | Cosserat multiplier (v2 only) | P0, one per element, a Newton unknown |
| $\gamma_a$, $a=1,2,3$ | slip on the three in-plane systems | P0 internal |
| $w^*$ | grain-boundary plastic spin | P0 internal |
| $F_p$ | plastic distortion, $F_p(0)=I$ | P0 internal |
| $\rho_S$, $\rho_M$ | statistically stored and mobile dislocation densities | P0 internal |
| $\rho_G$ | geometrically necessary density (derived from $F_p$) | P0 |

The deformation gradient splits multiplicatively:

$$F = I+\nabla u = R(\theta)\,\bar U\,F_p .$$

**Reference lattice.** Each element carries its grain angle $\theta_g$ (from `grain_angles_rad.txt` by region label), which rotates the cubic stiffness and the slip systems. The KWC terms see the total orientation $\theta_t=\theta_0+\theta$, with $\theta_0$ the smoothed grain angle, $\theta_0-\ell_s^2\Delta\theta_0=\theta_g$, $\ell_s=0.04$ µm. The VTU field `theta_lattice_deg` is $\theta_t$.

**Slip systems.** Planar triple slip of a [1-10] FCC crystal, lattice axes $x=[110]$, $y=[001]$: directions $s_1=(1,0)$ and $s_{2,3}=(\cos\alpha,\pm\sin\alpha)$ with $\alpha=\arctan\sqrt2$; normals $n_a$ = $s_a$ rotated by $+90°$; all rotated by $\theta_g$; system factors $f_a=(\sqrt3,\,2/\sqrt3,\,2/\sqrt3)$.

**Plastic flow.** With $\hat W=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$:

$$\dot F_pF_p^{-1}=\sum_a\dot\gamma_a\,s_a\otimes n_a+\dot w^*\,\hat W .$$

**Elastic measures.** Green strain $\bar E=\tfrac12(\bar U^T\bar U-I)$, Jacobian $J=\det\bar U$, Cosserat skew measure $a=\tfrac12(\bar U_{21}-\bar U_{12})$.

# 3. Free energy

$$\Psi=\int_\Omega(\psi_e+\psi_K+\psi_s)\,dA\quad\big(+\textstyle\sum_e\lambda_e\int_e a\,dA\ \text{in v2, Section 3.8}\big).$$

## 3.1 Elastic part: Vinet equation of state

$$\psi_e = W(J)+\tfrac12\tilde E_\parallel:\mathbb C_\parallel:\tilde E_\parallel+\tilde E_{33}\,B:\tilde E_\parallel+\tfrac12 C_{33}\tilde E_{33}^2+2\mu_c a^2 .$$

- $\tilde E=\tfrac12(J^{-2/3}\bar C-I)$ is the isochoric Green strain, $\tilde E_{33}=\tfrac12(J^{-2/3}-1)$ (nonzero in plane strain because $\bar U_{33}=1$ and the factor $J^{-2/3}$ scales it).
- $\mathbb C_\parallel$ is the in-plane block of the cubic stiffness acting on $(\tilde E_{11},\tilde E_{22},\tilde E_{12})$.
- $B_{ij}=C_{ij33}$; in the lattice frame $B=\operatorname{diag}(C_{xxzz},C_{yyzz})$, rotated by $\theta_g$: $B_{11}=C_{xxzz}c^2+C_{yyzz}s^2$, $B_{22}=C_{xxzz}s^2+C_{yyzz}c^2$, $B_{12}=(C_{xxzz}-C_{yyzz})cs$.
- $C_{33}=C_{zzzz}=C_{xxxx}$, since $z=[\bar110]$ is equivalent to $x=[110]$.
- The cross term has no factor ½ because it occurs twice in the full 3D quadratic form.

**Volumetric law (Vinet).** With $x=J^{1/3}$ and $\eta=\tfrac32(K'-1)$:

$$P=3K_0\frac{1-x}{x^2}\,e^{\eta(1-x)},\qquad W(J)=\frac{9K_0}{\eta^2}\Big[1-\big(1-\eta(1-x)\big)e^{\eta(1-x)}\Big],$$

with $P=-dW/dJ$, $W(1)=W'(1)=0$, $W''(1)=K_0$, and tangent bulk modulus $K(J)=\dfrac{K_0}{x^2}\big[2-x+\eta x(1-x)\big]e^{\eta(1-x)}$.

**Values.**

| Quantity | Value |
|---|---|
| $K_0=(C_{11}+2C_{12})/3$ (`-k0 0` selects this) | 137.1 GPa |
| $K'$ (`-kp`) | 5 |
| $C_{xxxx},C_{yyyy},C_{xxyy},C_{xyxy}$ | 220.3, 168.4, 121.4, 75.4 GPa |
| $C_{xxzz},C_{yyzz}$ | 69.5, 121.4 GPa |
| $\mu_c$ (`-muc`) | 754 GPa ($=10\,C_{xyxy}$; both set-ups) |

The cubic constants are those of Cu (Overton and Gaffney 1955, 300 K). Elastic coefficients are frozen at $T_0=300$ K, with no thermal expansion. In v2 the term $2\mu_ca^2$ is the augmentation of an exact constraint (Section 3.8); in `OLD=1` it is the penalty itself.

## 3.2 KWC boundary energy

$$\psi_K=f_0\Big[\tfrac12(1-\phi)^2+\tfrac12a_K^2|\nabla\phi|^2+s_K\,g(\phi)\,N(\nabla\theta_t)\Big],$$

$$g(\phi)=-2\big[\phi+\ln(1-\phi)\big],\qquad g'(\phi)=\frac{2\phi}{1-\phi},\qquad N(p)=\sqrt{|p|^2+\delta^2}-\delta .$$

- $\phi$ is kept in $[0,\,1-10^{-7}]$ by the active-set phase solve (Section 6.10), because $g$ diverges at $\phi=1$.
- Couple stress: $m=f_0\,s_K\,g(\phi)\,\dfrac{p}{\sqrt{|p|^2+\delta^2}}$, $p=\nabla\theta_t$.
- There is no $\epsilon_K^2|\nabla\theta_t|^2$ term.

| Parameter | Option | Value |
|---|---|---|
| $f_0$ | `-f0` | 0.005944 GPa |
| $a_K$ | `-kwca` | 0.10 µm |
| $s_K$ | `-kwcs` | 1.05 |
| $\delta$ | `-kwcd` | $5\times10^{-4}$ rad/µm (both set-ups; the base solver's default is 0.005) |

$\delta$ is the regularisation of the total-variation term $|\nabla\theta_t|$; it sets how sharp a boundary can be and how stiff the KWC Newton problem is. On the coarse test mesh the solution at $\delta=5\times10^{-4}$ differs from $\delta=5\times10^{-7}$ by $6.0\times10^{-4}$ (largest nodal difference in $U$), against $1.8\times10^{-3}$ at $\delta=0.005$; the difference falls by about 3 per decade of $\delta$, so $5\times10^{-4}$ is not converged in $\delta$. Exactly $\delta=0$ was tried by splitting methods and did not converge (`v2/README.md`, Tried and removed).

The values of $f_0,a_K,s_K$ come from a Read–Shockley fit for Cu ($\gamma_m=0.6$ J/m², $\theta_m=15°$), made with the earlier code on a 0.05 µm grid: within about 15% over 1–60° there, and 6–8% lower on a 0.025 µm grid. The boundary energy therefore depends on the mesh; the remeshing test A2 measured it again for 1–15° boundaries (at $h=0.1$ µm it is 11–27% above $h=0.025$ µm). The fit was made with $\delta=0.005$ and has not been redone for $5\times10^{-4}$.

## 3.3 Stored energy

$$\psi_s=\tfrac12\chi\mu b^2\,\phi\,\rho_S,\qquad Z=\tfrac12\chi\mu b^2\phi,$$

with $\chi=1$, $\mu=48$ GPa, $b=2.556\times10^{-4}$ µm. The factor $\phi$ makes the boundary core absorb stored dislocations.

## 3.4 Conjugate quantities

$$\Pi=\frac{\partial\psi_e}{\partial\bar U},\quad M=\bar U^T\Pi\ \text{(Mandel)},\quad P=R\,\Pi\,F_p^{-T},\quad \sigma=PF^T/J,\quad \frac{\partial\psi_e}{\partial\theta}=-\Pi:(\hat W\bar U).$$

The Cosserat term contributes $\mp(2\mu_ca+\tfrac12\lambda)$ to $\Pi_{12},\Pi_{21}$ ($\lambda=0$ with the penalty, `-almc 0`), and through $\partial\psi_e/\partial\theta$ it produces the finite-strain spring torque of Section 3.5.

## 3.5 The Cosserat spring: derivation

The general 3D theory is in `cosserat_kwc_theory_3d.md`; this section and 3.6–3.8 are its 2D plane-strain specialisation.

The lattice rotation $\theta$ is an independent field. What ties it to the displacement is the skew part $a$ of the elastic stretch $\bar U$: the penalty $2\mu_ca^2$ in `OLD=1`, the constraint $\bar a_e=0$ with the same term as augmentation in v2.

**Small strain.** Write $F=I+\nabla u$, $F_p=I+H_p$ and $R(\theta)\approx I+\theta\hat W$, with all of $\nabla u$, $H_p$, $\theta$ small. To first order

$$\bar U=R(\theta)^TFF_p^{-1}\approx I+\nabla u-\theta\hat W-H_p .$$

Since $\hat W_{21}-\hat W_{12}=2$, the skew combination is

$$\bar U_{21}-\bar U_{12}=(\partial_xu_2-\partial_yu_1)-2\theta-(H_{p,21}-H_{p,12}) .$$

With the material rotation $\omega(u)=\tfrac12(\partial_xu_2-\partial_yu_1)$ and the plastic spin $\omega_p=\tfrac12(H_{p,21}-H_{p,12})$ (the slip part $\sum_a\gamma_as_a\otimes n_a$ plus the boundary spin $w^*$),

$$a=\tfrac12(\bar U_{21}-\bar U_{12})=\omega(u)-\omega_p-\theta .$$

Varying $u\to u+\epsilon v$ and $\theta\to\theta+\epsilon\zeta$ at fixed $F_p$ gives

$$\delta(2\mu_ca^2)=4\mu_c\,(\omega(u)-\omega_p-\theta)\,(\omega(v)-\zeta) .$$

Equivalently, $\partial\psi/\partial\bar U_{21}=+2\mu_ca$ and $\partial\psi/\partial\bar U_{12}=-2\mu_ca$.

**What the penalty enforces (`-almc 0`, not used in production).** The $\theta$ balance is $\rho j\ddot\theta=\operatorname{Div}m+4\mu_ca$ at small strain. Where inertia and the couple stress are small, $\theta=\omega(u)-\omega_p$; the residual $a=-\operatorname{Div}m/(4\mu_c)$ is the lattice rotation that the couple stress holds away from the material rotation. It is a modelling error of the penalty, of order $|\operatorname{Div}m|/(4\mu_c)$.

**Finite strain.** $F_e=FF_p^{-1}=R(\varphi_e)S$ with $S=S^T>0$, so $\bar U=R(\beta)S$ with $\beta=\varphi_e-\theta$ and

$$\bar U_{21}-\bar U_{12}=\sin\beta\,\operatorname{tr}S,\qquad a=\tfrac12\operatorname{tr}S\,\sin\beta,\qquad 2\mu_ca^2=\tfrac12\mu_c(\operatorname{tr}S)^2\sin^2\beta,\qquad \frac{\partial\psi}{\partial\theta}=-\tfrac12\mu_c(\operatorname{tr}S)^2\sin2\beta .$$

- **Small-strain limit:** $-4\mu_c\beta$ for $S\to I$, small $\beta$.
- **Period:** $\pi$-periodic in $\beta$, with a second stable state at $\beta=\pi$ and a sign change of the torque at $|\beta|=\pi/2$. Neither the energy nor the constraint selects the branch $\beta\approx0$: $a=0$ also holds at $\beta=\pi$ ($\bar U=-S$ is symmetric too). The branch is enforced by the guard `-betamax` (Section 6.5), which measures $\beta=\operatorname{atan2}(\bar U_{21}-\bar U_{12},\bar U_{11}+\bar U_{22})$ per element (exact, since $\operatorname{tr}S>0$). A shift $\theta\to\theta+2\pi n$ is not another branch: $\bar U$ depends on $\theta$ through $\cos\theta,\sin\theta$ only, so it changes nothing but $\nabla\theta$, and only where neighbouring nodes do not shift together (which the KWC energy penalises). The log column `max_abs_dtheta_deg` is $\max|\theta|$ (the Cosserat rotation from the grain reference orientation), not $\beta$; $\max|\beta|$ per step is the last column of `<out>_newton.csv`.
- **Stretch dependence:** the spring scales with $(\operatorname{tr}S)^2$: it softens under in-plane compression ($\operatorname{tr}S<2$) and stiffens under extension.

The code evaluates this exact form (`finiteStress()`, the Gauss-point energy and the plugin).

## 3.6 How the phase field couples to the rotation

1. **Couple stress** $\propto g(\phi)$, with $g(0)=0$: no resistance to a rotation gradient inside a core, strong resistance in grains.
2. **Boundary spin** $\dot w^*=\tau^*(1-\phi)^2/(2\eta^*_0)$ (Section 5.2): frozen at $\phi=1$, free at $\phi=0$; it feeds $\omega_p$, so the lattice can turn relative to the material only where $\phi$ is low.
3. **Stored energy** $\psi_s\propto\phi\rho_S$: stored dislocations pull $\phi$ down.

**Stationary profile.** Without time dependence, curvature of $\phi$ or stored energy, Section 5.3 gives $(1-\phi)^2=2s_KN\phi$: $\phi=1$ where $\nabla\theta_t=0$, and $1-\phi\approx\sqrt{2s_KN}$ in a misorientation gradient. A stored density lowers $\phi$ further.

**Chain of cause.** Slip and misorientation gradients lower $\phi$; a lower $\phi$ opens the boundary spin and removes the couple stress; the lattice then follows $\omega(u)-\omega_p$; recovery clears $\rho_S$ behind a sweeping boundary.

## 3.7 Variational form of the balance laws

$$\int\Big[\rho\ddot u\cdot v+P:\nabla v\Big]=\text{boundary terms},\qquad \int\Big[\rho j\ddot\theta\,\zeta+m\cdot\nabla\zeta+\frac{\partial\psi_e}{\partial\theta}\zeta\Big]=0 ,$$

by $\delta u$ and $\delta\theta$ at fixed $F_p$, $\phi$, $\rho_S$, $T$ (in v2 also at fixed $\lambda$, with $j=0$, plus the constraint of Section 3.8); $\phi$, $\rho_S$, $F_p$ and $T$ follow the evolution laws of Section 5. The discrete residual (Section 6.4) is this weak form with the Gauss-point sum of Section 6.2 and the Newmark relations.

## 3.8 The Cosserat constraint in v2

**Constraint.** In every element $e$ the Gauss mean of the skew measure vanishes:

$$\bar a_e=\sum_{q=1}^3w_q\,a(F_q,\theta_q,F_{p,e})=0,\qquad w_q=\tfrac13 .$$

One multiplier $\lambda_e$ per element enforces it; the elastic energy at each Gauss point of $e$ becomes $\psi_e+\lambda_ea$, so $\lambda_e$ is a skew stress (it adds $\mp\tfrac12\lambda_e$ to $\Pi_{12},\Pi_{21}$). The stationarity conditions are the balance laws of Section 3.7 with this extra stress, together with $\bar a_e=0$.

**Augmentation, and what $\mu_c$ still does.** The constraint is one condition per element, on the quadrature mean. The Gauss-point values $a_q$ still vary within an element (not linearly in general: $a$ contains $\cos\theta$, $\sin\theta$ and $\theta$ is P1), and on the constraint the augmentation energy $2\mu_c\sum_qw_qa_q^2$ is $2\mu_c$ times their weighted variance. So $\mu_c$ remains a within-element energetic parameter of the discretisation, and it changes the discrete solution.

**$\mu_c$ study** (coarse test mesh, 10 relaxation + 10 loaded steps at 400 m/s, 45°, each run relaxed with its own $\mu_c$; differences are the largest nodal differences of $u$ and $\theta$ at $t=0.1$ ns, relative to $\max|u|$):

| $\mu_c$ (GPa) | 0 | 75.4 | 754 | 2400 | 7540 | 24000 |
|---|---|---|---|---|---|---|
| multiplier against multiplier at 24000: $u$ / $\theta$ | 61% / 0.64° | 36% / 0.094° | 14% / 0.040° | 5.9% / 0.028° | 2.9% / 0.017° | — |
| multiplier against penalty at the same $\mu_c$: $u$ / $\theta$ | — | 29% / 0.14° | 9.1% / 0.038° | 4.7% / 0.013° | 2.1% / 0.006° | 0.7% / 0.002° |
| Newton iterations per step, multiplier / penalty | 13.7 / — | 11.2 / 5.5 | 6.5 / 6.7 | 12.0 / 14.1 | 21.6 / 21.5 | 23.7 / 24.0 |

- The μ_c = 24000 run is a comparison solution, not an established limit, and both rows fall only slowly with μ_c (14% at the production value 754): the μ_c dependence is a modelling sensitivity to carry into interpretation. Multiplier and penalty approach each other as $\mu_c\to\infty$; their difference falls like $1/\mu_c$. That limit is $a_q=0$ at every Gauss point, which the element multiplier alone ($\mu_c=0$) does not impose: it fixes only the element mean, and is the furthest from the limit (largest rotation 0.63° against 0.18°; in an older, longer test it ran away to 39.7°). A multiplier per Gauss point, which imposes the limit directly, locks (`v2/README.md`).
- At equal $\mu_c$ the multiplier and the penalty differ by less than either differs from the limit: the within-element part of $a$, which only $\mu_c$ controls, carries most of the $\mu_c$ dependence. What the multiplier adds is $\bar a_e=0$ exactly (centroid $|a|\le5\times10^{-7}$, against $2\times10^{-4}$ for the penalty at 754 GPa).
- Iterations are lowest near 754 GPa for both and rise steeply above (conditioning). The solver refuses `-muc 0` with the multiplier.

754 GPa is the production value; these numbers are an early-time coarse-mesh test, and a $\mu_c$ study on the production mesh has not been made.

**Why the constraint.** The penalty (`-almc 0`) leaves the error $a=-\operatorname{Div}m/(4\mu_c)$, which becomes large exactly where boundaries are sharp; raising $\mu_c$ to remove it makes the problem stiff. The multiplier removes it from the element means at any $\mu_c>0$ (the within-element part remains, see above). In the idealised rigid, stress-free limit (element-mean quantities, one rotation mode) the lattice rotation then follows the standard KWC gradient flow $\eta_s\dot\theta=\operatorname{Div}m$, where the penalty gives $\eta_s\dot\theta=\operatorname{Div}m+(\eta_s/4\mu_c)\,\partial_t\operatorname{Div}m$: with the constraint, the spin viscosity $\eta_s=2\eta^*_0/(1-\phi)^2$ alone sets how fast boundaries rotate.

# 4. Balance laws and boundary conditions

$$\rho\ddot u=\operatorname{Div}P,\qquad \rho j\,\ddot\theta=\operatorname{Div}m+\Pi:(\hat W\bar U),\qquad \bar a_e=0\ \text{(v2)},$$

with $\rho=8.96$ GPa·ns²/µm² and micro-inertia $j$ = `-j` 0 (`OLD=1`: 0.01 µm², with $\theta$ integrated by Newmark like $u$).

**Quasi-static lattice rotation (v2).** With $j=0$ the $\theta$ equation has no inertia: at every instant $0=\operatorname{Div}m+\Pi:(\hat W\bar U)$, an elliptic equation for $\theta$ given $u$, $F_p$ and $\phi$. $\theta$ is kinematic (it is the rotation of the lattice, carried by the material and by plastic spin), so a micro-inertia has no physical value to take; with the constraint, the dissipation of lattice rotation sits where it belongs, in the boundary spin $w^*$ (Section 5.2). The earlier gradient-flow form of most KWC works corresponds to the rigid limit of Section 3.8. The kinetic energy of $\theta$ is zero, and the Newmark acceleration of $\theta$ is not used.

**Loading (angled plate).**

- Left edge (label 1) clamped.
- Right edge (label 3) is the plate: $u_x=-d_n(t)$, $u_y=+d_t(t)$. A plate speed $V$ at angle ANGLE (degrees from $-x$) splits into $V_n=V\cos(\text{ANGLE})$ (`-pistonup`) and $V_t=V\sin(\text{ANGLE})$ (`-pistonut`): 0° is compression, 90° is shear. Top and bottom edges are free.
- $d(t)$ integrates the plate speed: quintic ramp over `-ptr` 0.5 ns, hold for `-pth` 2.0 ns, quintic ramp down. Total simulated time `-tend` 30 ns.

**$\theta$, $\phi$, $T$:** natural conditions only: $m\cdot N=0$, $\nabla\phi\cdot N=0$, insulated boundaries. $\lambda$ has no boundary condition (one value per element).

# 5. Evolution laws

## 5.1 Slip

$$\tau_a=M:(s_a\otimes n_a),\qquad x_a=\frac{|\tau_a|}{f_a\tau_c},\qquad \frac1{|\dot\gamma_a|}=\frac{1}{\dot\gamma_0x_a^m}+\frac{\eta_{\rm eff}}{|\tau_a|},\qquad \operatorname{sgn}\dot\gamma_a=\operatorname{sgn}\tau_a .$$

Thermal activation ($\dot\gamma_0=10^{-6}$ /ns, $m=50$) in series with viscous drag. The strength is

$$\tau_c=\big(\tau_0+\lambda_T\mu b\sqrt{\rho_S+\rho_G}\big)\max\!\big(1-\alpha_\mu(T-T_0),\ s_{\min}\big),$$

with $\tau_0=0.001$ GPa, $\lambda_T=0.3$, $\alpha_\mu=3.8\times10^{-4}$ /K, $s_{\min}=0.01$ (`-softmin`).

**Drag.**

$$\eta_d=\frac{B_0\,T/T_0}{b^2\rho_m},\qquad \eta_{\rm eff}=\eta_d\sqrt{1+\Big(\frac{|\tau|}{\eta_d\,\rho_m b v_c}\Big)^2},$$

with $B_0=2\times10^{-5}$ GPa·ns and $v_c=2$ km/s (`-vc 2`), which bounds $|\dot\gamma|\le\rho_m b v_c$. The drag density is the evolved mobile density, $\rho_m=\min(\rho_M,\rho_S+\rho_G)$, floored at $10^{-3}$ µm⁻².

**Evaluation (exact in both set-ups; the base solver caps it).** The rate is a smooth, well-conditioned function of $\tau$ for every $x$: at fixed $\eta_{\rm eff}$ the slope $d\ln|\dot\gamma|/d\ln x$ lies between 1 and $m$, and the relativistic drag lowers it, towards 0 as the rate approaches its limiting value (a rate insensitive to $\tau$ is still well conditioned; only the inverse map would not be). Only the naive evaluation overflows ($x^m$ for $x\gtrsim1.4\times10^6$). v2 (`-slipexact 1`) evaluates it exactly: with $L=\ln(\dot\gamma_0\eta_{\rm eff}/(f_a\tau_c))+(m-1)\ln x_a$, the logarithm of the ratio of the drag term to the activation term, and $\sigma=1/(1+e^{-L})$,
$$|\dot\gamma_a|=\sigma\,\frac{|\tau_a|}{\eta_{\rm eff}},\qquad \frac{d|\dot\gamma_a|}{d|\tau_a|}=\frac{\sigma}{\eta_{\rm eff}}\big[m(1-\sigma)+\sigma\big]-\frac{\sigma}{\eta_{\rm eff}}\,|\dot\gamma_a|\,\frac{d\eta_{\rm eff}}{d|\tau_a|},$$
finite for all $x$ (with $1-\sigma$ computed as $1/(1+e^{L})$, without cancellation). Below $x=300$ it equals the previous evaluation to round-off ($10^{-15}$–$5\times10^{-13}$ relative); its derivative agrees with central differences to their round-off and with the drag-limited closed form at large $x$. `OLD=1` keeps the previous evaluation, which replaces $x_a$ by $\min(x_a,300)$ in the activation part: above 300 that rate stops growing with $|\tau|$ (at $x=600$ in the reviewer's example: 0.05 instead of the correct 0.1) and its derivative is that of the uncapped expression, so wrong there. Each run prints the largest $x_a$ at accepted states and the number of steps above 300 (coarse tests: 31 for `OLD=1`, 79 for v2).

## 5.2 Grain-boundary plastic spin

$$\tau^*=M_{21}-M_{12},\qquad \dot w^*=\frac{\tau^*}{\eta_s},\qquad \eta_s=\frac{2\eta^*_0}{(1-\phi)^2},\qquad \eta^*_0=1\ \text{GPa·ns (`-etastar`)} .$$

Discretely $\Delta w^*=k_s\tau^*$, $k_s=(1-\phi)^2\Delta t/(2\eta^*_0)$, with the element mean of $\phi$ at the start of the step. In v2 $\tau^*$ contains the multiplier stress ($M_{21}-M_{12}$ includes $\lambda$), which is how the couple stress drives the boundary spin.

## 5.3 Phase field

$$\eta_\phi(T)\,\dot\phi=f_0(1-\phi)+f_0a_K^2\Delta\phi-f_0s_Kg'(\phi)N(\nabla\theta_t)-\tfrac12\chi\mu b^2\rho_S ,$$

$$\eta_\phi(T)=\eta_{\phi0}\,\max\!\Big(\exp\!\Big[\frac{Q_\phi}{R}\Big(\frac1T-\frac1{T_0}\Big)\Big],\ r_{\min}\Big),$$

with $\eta_{\phi0}$ = `-etaphi` 0.1 GPa·ns under load ($10^{-3}$ in the relaxation stage), $Q_\phi$ = `-qphi` $10^5$ J/mol and $r_{\min}$ = `-etaphimin` $10^{-2}$. The floor caps the thermal speed-up at 100×; without it ($Q_\phi/R\approx12{,}000$ K) $\phi$ sits at equilibrium every step in hot regions and new low-$\phi$ regions heal within a step or two.

## 5.4 Dislocation densities

**Stored density** (explicit update after each converged step, $\Gamma=\sum_af_a|\Delta\gamma_a|$):

$$\Delta\rho_S=\frac{K}{b}\sqrt{\rho_S}\,\Gamma-\frac{2d}{b}\rho_S\,\Gamma-\Delta\rho_{\rm sweep},\qquad K=0.05,\ d=5\times10^{-4}\ \text{µm}.$$

- Saturation $\rho_{\rm sat}=(K/2d)^2=2500$ µm⁻²; $\rho_S(0)=10$ µm⁻²; floor $10^{-3}$.
- **Storage cap:** $Z\,\Delta\rho_{\rm store}\le\sum_a|\tau_a\Delta\gamma_a|$, so the stored energy never exceeds the plastic work.
- **Sweeping recovery** (Ask et al. 2019, Eqs. 80, 133):
$$\Delta\rho_{\rm sweep}=C_D\,\langle\Delta\phi\rangle^+\tanh\!\big(C_A^2|\nabla\theta_t|^2\big)\,\rho_S,\quad C_D=\texttt{-cd}\ 100,\ C_A=\texttt{-ca}\ \sqrt{10}\ \text{µm}.$$
  It acts only where $\phi$ increases (a sweeping or healing boundary) and a misorientation gradient exists. $\Delta\phi\ge1/C_D$ in one step clears $\rho_S$ to the floor.

**Mobile density** (backward Euler with the end-of-step forest density):

$$\rho_M^*=\rho_{\rm Msat}\Big(1-\sqrt{\rho_F/\rho_{\rm Fcut}}\Big)\ (\text{floored at }\rho_{\rm Mmin}),\quad \rho_F=\rho_{S,n+1}+\rho_{G,n+1},\quad \rho_{M,n+1}=\frac{\rho_{M,n}+C_2\Gamma\,\rho_M^*}{1+C_2\Gamma},$$

with $C_2$ = `-c2m` 10, $\rho_{\rm Msat}$ = `-rhomsat` 100 µm⁻², $\rho_{\rm Fcut}$ = `-rhofcut` $10^4$ µm⁻², $\rho_{\rm Mmin}$ = `-rhommin` 1 µm⁻².

**Geometrically necessary density:** $\rho_G=|c/J_p|/b$ (Cermelli–Gurtin, planar: $G=J_p^{-1}F_p(\operatorname{Curl}F_p)^T=e_3\otimes c/J_p$, no reference subtraction) with $c=\operatorname{Curl}F_p$, $(\operatorname{Curl}F_p)_i=\partial_xF_{p,i2}-\partial_yF_{p,i1}$, from the P0 $F_p$ by a weak form with boundary terms and the lumped P1 mass. $G_R$ is the field at the end of the relaxation, so only the load-produced content counts.

## 5.5 Heat and dissipation

$$\rho C\,\dot T=k\Delta T+D,\qquad D=\sum_a\tau_a\dot\gamma_a+\tau^*\dot w^*+\eta_\phi\dot\phi^2-Z\dot\rho_S ,$$

$\rho C=3.45\times10^{-3}$ GPa/K, $k=4\times10^{-4}$ GPa·µm²/(ns·K). The multiplier does no work at the solution ($\bar a_e=0$) and adds no dissipation.

**Spatial sampling of the plastic power (an approximation of the discretisation).** The plastic state is one P0 state per element, evolved with the driving forces at the element-mean (centroid) state, while the elastic energy and force use the three Gauss points; for a uniform element increment the driving force conjugate to that energy is the Gauss-point mean $\langle\tau\rangle_q$, not $\tau_c$. Tight Newton tolerances do not remove this difference. `powerSplit()` measures it at every accepted state, at the same trial plastic state and with the accepted increments $\delta q$: per element $P_c=\tau_c\cdot\delta q$ and $P_q=\langle\tau\rangle_q\cdot\delta q$. Two measures are reported, relative to $\sum_eA_e|P_c|$: the net $|\sum_eA_e(P_q-P_c)|$, which can cancel between elements, and the element-by-element $\sum_eA_e|P_q-P_c|$, which cannot; plus $\max|\langle\tau\rangle_q-\tau_c|/\max|\tau_c|$. The values are computed at the accepted mechanical state but published only when the whole coupled step has succeeded (phase field, densities, heat, commit without NaN): then the step is written to `<out>_power.csv` and added to the totals. On a resume `run.sh` drops the rows after the checkpoint, so the file holds the active history, each step once, across restarts and abandoned branches; the end-of-run line sums the loaded steps of that launch only and names them. These are endpoint plastic-work approximations, not finite-step elastic-energy differences. Coarse test, 400 m/s at 45°, loaded steps to 0.1 ns: net $1.1\times10^{-5}$, element by element $6.4\times10^{-4}$ of the plastic work (largest per step $9.5\times10^{-4}$), driving forces up to 0.55% apart. Its size on the production mesh and under refinement, later in the runs, is to be read from `_power.csv`; a quadrature-consistent driving force or plastic states at the Gauss points would remove it.

- **Phase-field dissipation:** the element average of $\eta_\phi(T)(\phi_{n+1}-\phi_n)^2/\Delta t$, integrated with the quadrature of the phase viscous term (the term the residual pairs with the increment). Before 15 November 2026 (third main-solver review) the code squared the element-mean increment, which drops the within-element variation of the P1 increment (zero heat for nodal increments $(0.01,-0.01,0)$, against $1.67\times10^{-5}\,\eta_\phi/\Delta t$; tested).
- **Heat source:** the implicit $\tau_{n+1}\Delta\gamma$, sign-definite for the backward-Euler local update when the local equations are solved (Section 6.5). Elements with a negative heat source after every correction (the SSD floor below included) are counted (`neg_D_count`; before 15 November 2026 they were counted before the floor correction).
- **SSD floor:** the floor $\rho_S\ge10^{-3}$ is applied before the stored-energy increment is closed, so heat = dissipation − the actual stored-energy change.
- Temperature feeds back through the softening of $\tau_c$, drag $\propto T$ and $\eta_\phi(T)$. The run stops gracefully if $T_{\max}>$ `-tstop` 1400 K.

# 6. Discretisation

## 6.1 Spaces

$[u_1,u_2,\theta]\in[P2,P2,P1]$ is one mixed space; $\phi,T,\theta_0\in P1$; all internal variables and $\lambda$ are P0.

## 6.2 Gauss-point elastic energy

$$E_{el}=\sum_eA_e\sum_{q=1}^{3}\tfrac13\,\big[\psi\big(F_q,\theta_q,F_{p,e}\big)+\lambda_e\,a\big(F_q,\theta_q,F_{p,e}\big)\big],\qquad F_q=I+\nabla u(\lambda_q),\quad \theta_q=\theta(\lambda_q),$$

at the three edge midpoints of each triangle (FreeFem's `qf2pT`, degree 2); $\lambda_e=0$ with the penalty (`-almc 0`).

- The internal force is $\sum_eA_e\sum_qw_q[P_q:\nabla\varphi+\partial_\theta\psi_q\varphi_\theta]$, with no reference quadratic energy and no correction term.
- $F_q$ and $\theta_q$ are exact linear combinations of nodal dofs (operators built once from the P2 basis).
- **Internal variables stay P0:** $F_p$, the slip increments and the local update use the element-mean state $(\bar F_e,\bar\theta_e)$.
- **No hourglass modes:** on a P2 triangle $\nabla u$ is linear, so its values at three non-collinear points (the edge midpoints) determine it everywhere in the element: the stacked operator of the full gradient has rank 10 (12 dofs minus the two translations), the full rank. No deformation of the element escapes the sampling, which is what an hourglass mode is, so the rule is not underintegrated in that sense, linear or nonlinear ($F$ itself is sampled exactly). The symmetric strain has rank 9; the missing direction is the rigid rotation, which carries energy through the Cosserat coupling to $\theta$. The rule integrates the energy density inexactly (it is not a polynomial), which is a quadrature error, not a zero-energy mode; no stabilisation is used.
- **P2 displacement** avoids locking: $K_0/\mu\approx2$–3 and $\det F_p=1$.

## 6.3 Time integration

Newmark average acceleration ($\beta=\tfrac14,\gamma=\tfrac12$; $c_0=4/\Delta t^2$, $c_1=4/\Delta t$), $\Delta t$ = `-dt` 0.01 ns:

$$A_{n+1}=c_0(U_{n+1}-U_n)-c_1V_n-A_n,\qquad V_{n+1}=V_n+\tfrac{\Delta t}2(A_n+A_{n+1}).$$

- **Predictor:** $U_n+\Delta tV_n$ with the prescribed plate displacement; $\lambda$ and the dual flux $w$ start from their values at the end of the previous step.
- **Prescribed dofs:** their displacement is the exact plate displacement, and the inertial load of the step uses their exact acceleration ($-a_p$ on the plate face, 0 on the clamped edge) in place of the Newmark value $c_0(g_{n+1}-U_n)-c_1V_n-A_n$. The consistent mass couples it into the free equations and the reactions (plate work); $U$ is fixed on these dofs, so the tangent does not change. After the commit (and on restart) they carry the exact velocity and acceleration, so the state committed is the state the equations were solved with. Before 15 November 2026 the equations used the Newmark value and the commit overwrote it: during the ramp the two differ by up to 66% of the exact acceleration in the first step and 5% at 0.1 ns (coarse test, 0.0217 against 0.434 µm/ns²), and the solution by 0.7% of $\max|U|$ at 0.1 ns. Newmark-consistent prescribed kinematics without the overwrite (the other consistent choice) differs from the fixed scheme by $1.1\times10^{-6}$, 4% of that change.
- With $j=0$ (v2) the $\theta$ dofs carry no mass, so the Newmark terms do not enter their equations. $\theta$ is still updated by the Newmark recurrence like every dof, and the VTU field `theta_dot` is that Newmark rate; it is not governed by an equation of its own.

Newmark average acceleration is unconditionally stable for linear problems. That result does not cover this scheme as a whole, which is nonlinear and staggered, with explicit density updates, bound constraints and nonlinear solves to a tolerance; $\Delta t$ and the element size also set the accuracy of the waves (dispersion).

**Time-step study** (coarse mesh, 400 m/s at 45°, same relaxed start, to 0.1 ns, after the fixes of 15 November):

| $\Delta t$ (ns) | 0.01 | 0.005 | 0.0025 |
|---|---|---|---|
| $\max\lvert U-U_{\Delta t/2}\rvert/\max\lvert U\rvert$ | 5.0% | 2.2% | — |
| heat $Q$ (relative change from the next finer step) | 3.6% | 1.3% | — |
| largest temperature rise (K) | 0.0371 | 0.0351 | 0.0342 |
| energy audit (`audit_full`, of the plate work) | −0.83% | −0.45% | −0.20% |

These are differences between successive time steps, not a convergence certificate. The observed order is about 1.2: the backward-Euler local update, phase field and heat equation are first order, and so is the one-pass staggering (mechanics, then phase field, densities, heat), whose error nonlinear tolerances do not bound; Newmark (second order) covers only the elastodynamics. Richardson extrapolation, which assumes the asymptotic regime, puts the error of $\Delta t=0.01$ at about 9% of $\max|U|$ at 0.1 ns. This is the start of the ramp on the coarse mesh, where the plate jerk is largest; a study on the production mesh over a physically relevant window ($\Delta t$ 0.01 against 0.005, refined further if the difference exceeds the accuracy needed; stress, temperature, slip and grain-boundary measures as well as displacement) has not been made and should precede quantitative use of the MPI runs, which use 0.01 (serial runs use 0.005; 0.005 is not converged merely because it is smaller). The raw outputs of this study are in `docs/evidence/` of the review package.

## 6.4 Global residual and constraint residual

$$R(U,\lambda)=F_{\rm ext}+F_{\rm el}(U,\lambda)-c_0(M_u+M_\theta)U+(M_u+M_\theta)(c_0U_n+c_1V_n+A_n)-(M_u+M_\theta)\big(a_D^{\rm exact}-a_D^{N}\big)-B_K ,\qquad c_e(U)=\bar a_e ,$$

where $a_D^{N}=c_0(U-U_n)-c_1V_n-A_n$ restricted to the prescribed dofs (zero on the free dofs) and $a_D^{\rm exact}$ the exact plate acceleration there: the inertial load is $M_{ff}a_f^N+M_{fD}a_D^{\rm exact}$ on the free rows (Section 6.3). The correction is constant during the Newton iteration ($U$ is prescribed on these dofs).

with $F_{\rm el}$ the Gauss-point force (including the multiplier stress), $B_K=\int m\cdot\nabla\zeta$ the KWC couple stress from the element-mean $\nabla\theta_t$ and the element mean of $g(\phi)$, and $M_\theta=0$ in v2. Dirichlet dofs are masked. In `OLD=1` there is no $\lambda$ and no $c$.

## 6.5 Element map and local update

Per element, the map $\mathcal M:(k,q;\lambda)\mapsto(s,\tau,a)$ is closed-form: $k=(F_{11}-1,F_{12},F_{21},F_{22}-1,\theta)$ the kinematics, $q=(\Delta\gamma_{1..3},\Delta w^*)$ the increments, $s=(P_{11},P_{12},P_{21},P_{22},\partial\psi/\partial\theta)$ the stresses, $\tau=(\tau_{1..3},\tau^*)$ the driving forces, $a$ the skew measure.

1. **Exact exponential.** $\Delta L_p$ is traceless, so $\exp(\Delta L_p)=c\,I+s\,\Delta L_p$ (Cayley–Hamilton), $q^2=-\det\Delta L_p$: $c=\cosh q$, $s=\sinh q/q$ for $q^2>0$; $c=\cos w$, $s=\sin w/w$ for $q^2=-w^2<0$. The solver bounds $|q|$ below by $10^{-8}$ (where $c=s=1$ to double precision). The plugin evaluates the same functions as power series in $q^2$ for $|q^2|<1$ (smooth through $q^2=0$, as differentiation needs) and in closed form otherwise; the two agree to $3\times10^{-13}$.
2. **Cap and rejection.** The argument is capped at 50; a trial with $|q|>50$ is not volume preserving and the iterate is rejected (Newton abandoned, then retry or clean stop).
3. $F_p^{\rm trial}=\exp(\Delta L_p)F_{p,n}$, $\bar U=R(\bar\theta)^T\bar FF_p^{-1}$, then stresses (Section 3.4) and drives $\tau_a,\tau^*$.

**Local equations** (backward Euler):

$$r_a=\Delta\gamma_a-\Delta t\,\operatorname{sgn}(\tau_a)\,|\dot\gamma|(\tau_a)=0,\qquad r_*=\Delta w^*-k_s\tau^*=0 .$$

**Solution.** (i) Robust loop of up to `-nlocal` 30 iterations: a spin Newton step plus a 3×3 slip Newton step with per-element backtracking and the drag bound $|\Delta\gamma_a|\le2\Delta t|\tau_a|/\eta_{\rm eff}$. (ii) Coupled polish: up to `-polish` 20 Newton iterations with the exact 4×4 Jacobian and backtracking (1, ½, ¼, ⅛); it stops when the residual is below $10^{-14}$ or no longer halves.

**Acceptance test on the local residual (`-localtol` $10^{-10}$, both set-ups).** After the global Newton has converged, the solver makes the final state of the step (below) and evaluates on it the four local residuals $|r_1|+|r_2|+|r_3|+|r_*|$ per element (increment units, the residual the local solver works with). If the largest exceeds $10^{-10}$ (`LOCALTOL`), the step is not accepted: it goes to the retry path with a fresh tangent and, if the test fails again, the run stops cleanly with the checkpoint of the previous step (Section 6.8). A spin increment held at the spin cap leaves $r_*\neq0$, so such a state is rejected rather than treated as a root. Each run prints the largest residual and the number of rejections; the end of every run also prints the largest residuals of both local stages at accepted states, and the log column `locres` has the robust-loop value per step. Coarse tests: largest $5\times10^{-15}$, no rejection; the 90° production run (before the test existed): polish residual median $9\times10^{-15}$, 99th percentile $1.4\times10^{-14}$ at converged iterations. (The base solver has no such test.)

**Spin branch** `-spinbranch` π/4: bounds $|\Delta w^*|$ in the iterates. The energy is π-periodic in $w^*$, so the local spin equation has spurious roots near $n\pi$ where $k_s$ is large; physical increments are ~$10^{-3}$ rad, so the bound never binds a converged state.

**Rotation branch** `-betamax` π/4 (both set-ups). Every residual evaluation measures $\max|\beta|$ (Section 3.8) at the three elastic Gauss points of every element and at the element means, over all elements. An iterate with $|\beta|>2\,$betamax ($\pi/2$, where the Cosserat torque changes sign) is inadmissible like one that fails the $\det F$ bound: the line search backtracks, and an iterate that cannot be rescued fails the attempt. A converged state needs $|\beta|\le$ betamax, otherwise it goes to the retry path and then to a clean stop, like the local acceptance test. This removes the spurious root $\beta\approx\pi$ (rotation and stretch flipped by half a turn, $\bar U\approx-S$) on which a Newton iteration can land after a large rotation increment; on such a root the stress, the dissipation and the temperature are wrong, which is one way a single step could heat an element by hundreds of kelvin (not established as the cause of the observed jumps). Physical values are below a few degrees (coarse tests: see `v2/README.md`). The end of each run prints the largest accepted $|\beta|$ and the numbers of rejected iterates and steps.

**Final state of a step (with `-localtol` or `-betamax`, i.e. always in production).** After the global Newton converges, the solver does one last local update and then evaluates, on that same state, the global residual (and with it the reaction on the prescribed dofs used by the plate-work ledger), the constraint $\max_e|\bar a_e|$, the admissibility checks ($\det F$ bound, $|q|\le50$, $|\beta|\le2\,$betamax), the local residuals and $|\beta|\le$ betamax. The step is accepted only if all hold, the merit being no larger than the one the Newton accepted (to $10^{-3}$ relative, or below its tolerance) and $\max|\bar a_e|\le10^{-8}$; a failure goes to the retry path, then to a clean stop. The accepted state is the one committed: the time loop's own final local update is skipped. The end of each run prints the number of final-state rejections.

## 6.6 Exact consistent tangent

**Mechanical part.** The matrix is the exact derivative of the Gauss-point force, including the implicit slip and spin response:

$$K=\frac{\partial f_{\rm int}}{\partial U}=\sum_e\sum_{q}A_ew_q\,G_q^T\Big[H_q\,G_q+\Big(\frac{\partial s}{\partial q}\frac{dq}{dk}\Big)_q\bar K\Big],\qquad H_q=\frac{\partial s}{\partial k}\Big|_q,$$

with $G_q$ the Gauss-point kinematics operator and $\bar K$ the element-mean operator.

- $\partial s/\partial k$, $\partial s/\partial q$, $\partial\tau/\partial k$, $\partial\tau/\partial q$ come from **forward-mode automatic differentiation** of the element map in the plugin (`k2dJac`; dual numbers of `dual.hpp`, OpenMP over elements), exact to round-off. In v2 `k2dJacL` adds $\lambda$ as a tenth differentiated input and $a$ as an extra output, giving $\partial a/\partial(k,q)$, $\partial s/\partial\lambda$ and $\partial\tau/\partial\lambda$ in the same pass.
- The local equations are differentiated analytically (including $|\dot\gamma|'$ with the relativistic drag): $dq/dk=-(\partial r/\partial q)^{-1}\partial r/\partial k$, a 4×4 solve per element; v2 adds a sixth right-hand side for $dq/d\lambda$. Where $|\Delta w^*|$ sits on the spin cap, that row is replaced by $dq_w=0$.
- Inertia and Dirichlet rows are exact. The matrix is not symmetric.

**Constraint blocks (v2).** Newton on $(U,\lambda)$ solves

$$\begin{pmatrix}K&C\\B&E\end{pmatrix}\begin{pmatrix}\Delta U\\\Delta\lambda\end{pmatrix}=\begin{pmatrix}R\\-\bar a\end{pmatrix},$$

$$B_e=\sum_qw_q\Big[\frac{\partial a_q}{\partial k}G_q+\frac{\partial a_q}{\partial q}\frac{dq}{d\bar k}\bar K\Big],\qquad C_{\cdot e}=\sum_qA_ew_q\,G_q^T\Big[\frac{\partial s_q}{\partial\lambda}+\frac{\partial s_q}{\partial q}\frac{dq}{d\lambda}\Big],\qquad E_{ee}=\sum_qw_q\frac{\partial a_q}{\partial q}\frac{dq}{d\lambda}.$$

$B$ has one row per element, $C$ one column per element, $E$ is diagonal and negative (from $-1/(4\mu_c)$ down to about $10^{-7}$ where plastic spin is free, so $\lambda$ cannot be eliminated element by element). $C$ equals $\operatorname{mask}\cdot B^T\operatorname{diag}(A_e)$ to $10^{-3}$: the system is a symmetric saddle point up to the plastic part. $B$ and $C$ are assembled directly from per-element coefficients on the 15 element dofs.

**KWC part.** The flux $m=c_e\,g_e/n_e$ per element ($g_e=\nabla\theta_t$, $n_e=\sqrt{|g_e|^2+\delta^2}$, $c_e=f_0s_K\bar g(\phi)_e$) is the same in the residual of both set-ups. Its tangent:

- base solver and the self-test (`-kwctan 0`): the exact Hessian $H=(c/n)\big(I-g\,g^T/n^2\big)$.
- `-kwctan 2`: the **primal–dual** linearisation, symmetrised (Chan, Golub and Mulet 1999). A dual flux $w_e$ ($|w_e|\le1$), initialised to $g/n$, is updated after every Newton iteration by $\delta w=(I-w\,g^T/n)\,\delta g/n+g/n-w$, shortened per element so that $|w|\le1$ (0.99 of the boundary step); the tangent is $H=(c/n)\big(I-\operatorname{sym}(w\,g^T)/n\big)$. At convergence $w=g/n$ and $H$ equals the exact Hessian; during the iteration it is symmetrised and kept positive definite, which removes the stiffness of $N$ near $g=0$ at small $\delta$. It converges to the same solution as the exact tangent ($3\times10^{-14}$) in about half the iterations at $\delta=5\times10^{-4}$ (5.7 against 11.0 per step), and with a direct linear solve it still converges at $\delta=5\times10^{-7}$ (11.8 per step).

For the exact Hessian (`-kwctan 0`) the KWC tangent is exact element by element ($\nabla\theta_t$ is constant per element and $\bar g$ does not change during the mechanical step). The v2 primal–dual tangent is an iteration-dependent surrogate that equals the exact Hessian only when $w=g/n$; the residual it is used with is exact.

**Exact primal–dual Newton tangent (`-kwctan 3`, production since version 8.0).** The primal–dual system has the flux $m=c\,w$ and the dual equation $n\,w-g=0$. Its Newton linearisation, with $\delta w$ eliminated element by element, is $\delta m=(c/n)(I-w\,g^T/n)\,\delta g+c\,(g/n-w)$: the right-hand side is the primal residual $c\,g/n$ the solver already uses, and the tangent is $H=(c/n)(I-w\,g^T/n)$ without the symmetrisation. `-kwctan 3` uses this $H$: the exact reduced Newton tangent of the primal–dual system and its undamped direction at every iteration, not only at convergence. The update around it is safeguarded and is therefore not a plain Newton step: the primal step is backtracked by $\alpha$, and the dual update uses the accepted change of $g$, giving $\alpha T\delta g+b$ with $T=(I-w\,g^T/n)/n$, $b=g/n-w$, where a uniformly damped joint step would be $\alpha(T\delta g+b)$; it is then shortened per element to keep $|w|\le1$. Full Newton steps (and the quadratic rate) hold only where these safeguards are inactive ($\alpha=1$, no shortening). Only the $\theta\theta$ block changes: its antisymmetric part $(H_{12}-H_{21})/2$ is added in the forms and in the direct assembly (checked against each other to $1.6\times10^{-14}$). The dual update is the same as for `-kwctan 2`. Coarse tests, Newton iterations per step over 10 relaxation and 10 loaded steps, `-kwctan 2` against 3 (the solutions agree to $10^{-12}$ or better):

| | $\delta=5\times10^{-4}$ | $5\times10^{-6}$ | $5\times10^{-7}$ | penalty, $j=0.01$ (former `OLD=1`) |
|---|---|---|---|---|
| `-kwctan 2` (symmetrised) | 6.90 | 9.90 | 12.35 | 6.15 |
| `-kwctan 3` (exact) | 7.10 | 9.95 | 12.15 | 6.15 |

The exact tangent changes the iteration count by less than 3% either way: near convergence $w\approx g/n$ and the antisymmetric part is small, and what limits the convergence is the line search on the primal merit and the bound $|w|\le1$, not the tangent. Production uses `-kwctan 3` since version 8.0 (the kt3pcg runs); `-kwctan 2` remains available.

## 6.7 Assembly of the tangent matrix (`-asm 1`, both set-ups)

The mesh and the reference configuration are fixed, so most of the matrix machinery never changes. Built once per run: the sparsity pattern, the kinematic operators at the Gauss points and the centroid, the map from element entries to matrix entries, and the constant part (inertia, the viscous and boundary terms, Dirichlet rows). Rebuilt every Newton iteration: only the Gauss-point blocks $H_q$ and $(\partial s/\partial q\,dq/dk)_q$ (3 per element) and the KWC coefficients; the plugin (`k2dAsmJ`, `k2dAsmA`) turns them into matrix values in place.

The base solver (and `FASTASM=0`) assembles the same matrix by FreeFEM forms: two integrals with 53 coefficient fields and three sparse additions per iteration. Both give the same matrix (results agree to $3\times10^{-16}$); the direct assembly makes the tangent about 6 times faster (production mesh: 8.2 s against 51 s per step on 2 ranks). Two checks guard it:

- **Every iteration:** the solver compares $z^TAx$ of the matrix with the plugin's own sum for fixed vectors (tolerance $10^{-9}$ of $\sum|z_iA_{ij}x_j|$) and stops if they differ. This catches values in the wrong entries and not-a-number, not a wrong formula; the largest deviation of a run is printed at its end (typically $10^{-16}$).
- **`ASMCHECK=N` (opt in):** every $N$-th Newton iteration of the run, counted over all steps and starting with the first, each rank also assembles its matrix by the forms from the same element blocks and compares all entries outside the Dirichlet rows; the run stops if the largest difference exceeds $10^{-12}$ of the largest entry, and the end of the run reports the number of comparisons and the largest deviation. One comparison costs one form assembly (about 0.4 s on the coarse test mesh, serial). Measured: $1.6\times10^{-14}$ (v2) and $1.3\times10^{-15}$ (`OLD=1` physics), serial and on 2 ranks; a matrix corrupted by $10^{-9}$ is stopped at the first iteration.

`ASMCHECK` found one error, fixed on 15 November 2026: the plugin's set-up is made in the first matrix assembly of a run, after the element blocks of that first iteration had been handed over, so the first Newton iteration after every start or restart lacked the Gauss-point (elastic and plastic) part of the matrix. Converged steps were not affected (convergence is tested on the exact residual, and the mass term $c_0M$ dominates the matrix at $\Delta t=0.01$ ns): the 90° production run took the same 8 iterations in its first step after a restart as in the uninterrupted pass, with final residuals equal to 3 digits. The plugin now keeps blocks that arrive before the set-up.

The matrix values themselves cannot be frozen or factorised once: the Gauss-point blocks change with stress, slip and lattice rotation at every iteration.

## 6.8 Global Newton

- **Each iteration:** local update, tangent at the current iterate (`-tanevery 1`), residual, linear solve.
- **Merit function and line search:** backtracking on $\|R\|$ (penalty, `-almc 0`) or on $\sqrt{\|R\|^2+\sum_e(sA_e\bar a_e)^2}$, $s=4\max(\mu_c,75.4)$ GPa (v2; $U$ and $\lambda$ move together), halving, at most `-lsmax` 6 halvings; the last candidate is tested too, and if none decreases the merit the iterate is restored and the step fails into the retry path.
- **Convergence:** the relative increment $s\,\|\Delta U\|_\infty/\|U\|_\infty<$ `-tol` $10^{-7}$ ($s$ the line-search step; $U$ holds the $u$ and $\theta$ dofs together, with no separate scaling) and merit $\le$ `-tolres` $10^{-6}\max(\text{merit}_0,$ `-resfloor` $10^{-8})$, at most `-maxit` 40 iterations; v2 also requires $\max_e|\bar a_e|\le10^{-8}$.
- **Small increment:** a Newton exit on a negligible increment must also satisfy merit $\le$ `-stagres` $100\times$ tolres merit$_0$; otherwise it is a stagnation (retry, then a clean stop).
- **Determinant bound** (`-jmin 0.1`): every residual evaluation checks a rigorous lower bound of $\det F$ on each P2 triangle from the Bernstein coefficients of the quadratic $\det F$ (vertex values and $b_{ij}=2f(m_{ij})-\tfrac12(f_i+f_j)$); an inadmissible iterate is rejected.
- **Divergence:** $\|R\|>10^4\|R_0\|$ abandons the attempt.
- **Failure:** restore the predictor (and $\lambda$, $w$ to their step-start values), refresh the tangent, re-solve with `-maxitretry` 80. If that fails: clean stop, checkpoint at the end of the previous step, `<out>_stall<n>.vtu`, `<out>_NOCONV.txt`.

**Linear solver.**

| | v2 (both set-ups) | penalty (`-almc 0`, not used in production) |
|---|---|---|
| serial | sparse direct (FreeFEM `sparsesolver`) on $(U,\lambda)$ | GMRES (`-krylov` 100) + ILU to `-lintol` $10^{-10}$, direct solve when the checked residual misses $10^3\,$lintol |
| MPI | FGMRES(200) on the PETSc nested matrix, block upper-triangular Schur preconditioner (Section 10); MUMPS on the converted matrix for a solve that misses $10^3\,$lintol | GMRES(200) + ASM(overlap 1)/ILU (`-petsc`); MUMPS (`-petscfall`) when it misses the tolerance |

**The $(U,\lambda)$ preconditioner.** The Schur complement $S=E-BK^{-1}C$ is close to $-1/(4\mu_c)\,I$ because the augmentation $2\mu_ca^2$ is already inside $K$: on test matrices its diagonal lies between $-3.3\times10^{-4}$ and $-1.4\times10^{-4}$ and its off-diagonal part is 10% of the diagonal. A diagonal approximation of $S$ (the diagonal of $E-B\operatorname{diag}(K)^{-1}C$) gives eigenvalues of the preconditioned $S$ in about $[0.5,1.7]$; one ASM/ILU application approximates $K^{-1}$. On the production mesh (2 ranks, measured with the trial value $\eta^*_0=0.1$) this takes 36–40 FGMRES iterations per solve; the $(u,\theta)$ block alone with the v2 parameters takes 44–48 GMRES iterations (11–12 with the `OLD=1` parameters), so the count comes from $\mu_c=754$, $\delta=5\times10^{-4}$ and $j=0$, not from the multiplier. ILU(1), ILU(2), subdomain LU and GAMG were not faster.

## 6.9 Order of operations in a step

1. Step start: element means of $\phi^2$ and $g(\phi)$; strength, drag and $k_s$; v2: $\lambda$ and $w$ saved for a retry.
2. Predictor and the prescribed plate displacement.
3. Global Newton (Section 6.8), with retry.
4. Final local update.
5. Commit: Newmark update, external work, implicit dissipation, plate work.
6. Phase-field solve (Section 6.10), then sweeping recovery and $\phi$ dissipation.
7. Densities: $\rho_S$ storage and recovery with the storage cap, $\rho_G$, $\rho_M$.
8. Heat solve.
9. Output: energies and audit, logs, VTU, checkpoints; then the `-tstop` and wall-limit checks.

## 6.10 Phase-field step (after the mechanical step)

Backward Euler, Newton on the logarithmic coupling ($g''=2/(1-\phi)^2$); $N(\nabla\theta_t)$ is element-wise at the converged state, $\eta_\phi$ is evaluated at the start-of-solve $T$:

$$\int\Big[\Big(\tfrac{\eta_\phi}{\Delta t}+f_0+f_0s_KNg''(\phi_k)\Big)\phi\xi+f_0a_K^2\nabla\phi\cdot\nabla\xi\Big]=\int\Big[\tfrac{\eta_\phi}{\Delta t}\phi_n+f_0-\tfrac12\chi\mu b^2\rho_S-f_0s_KN\big(g'(\phi_k)-g''(\phi_k)\phi_k\big)\Big]\xi .$$

**Bound constraint by a primal-dual active set** (no penalty parameter). The solution lies in $[0,\phi_{\max}]$, $\phi_{\max}=1-10^{-7}$.

1. The multiplier of a bound is the nodal residual $r$ of the nonlinear phase equation (KKT: $r=0$ on free nodes, $r\ge0$ at $\phi=0$, $r\le0$ at $\phi_{\max}$).
2. A node is active when $\phi-r/d\notin[0,\phi_{\max}]$ ($d$ = lumped Jacobian diagonal), with a tolerance $0.1\times$`-phikkt`.
3. Active nodes are eliminated exactly ($\phi$ = bound, columns moved to the right-hand side, a lumped identity row); the free nodes solve the reduced system, by projected CG (Section 6.13).
4. Convergence: $\|\Delta\phi\|_\infty<$ `-phitol` $10^{-10}$ within `-phimaxit` 40 iterations **and** the KKT test (free nodes $|r|/d\le$ `-phikkt` $10^{-8}$, sign conditions at the bounds). Otherwise the run stops (`_NOCONV.txt`); the failed step is not checkpointed.

In the MPI code the elimination is applied to the rank-local matrices before assembly; the active flags come from owned nodes and are exchanged so all ranks agree, and the KKT test uses owned nodes only.

**Heat.** Backward Euler: $\int[\tfrac{\rho C}{\Delta t}T\xi+k\nabla T\cdot\nabla\xi]=\int[\tfrac{\rho C}{\Delta t}T_n+\tfrac{\Delta D}{\Delta t}]\xi$, with $\Delta D$ the P0 dissipation of the step.

## 6.11 Relaxation stage and restarts

Every run starts from the relaxed checkpoint of its set-up, `relax_checkpoint_v2.txt` (`OLD=1`: `relax_checkpoint_j.txt`; with a `RUNTAG`, `_<RUNTAG>` is appended), made once by `run_relax.sh` (the relaxation job the submit scripts queue first): `-nrelax` 100 zero-load steps with $\eta_\phi=10^{-3}$ GPa·ns, starting from $\phi=0.999$. The file is saved before the end-of-relaxation reset and is accepted only if its `.args` match the current option list. At the first start of a run the reset is applied:

- $\rho_S=\rho_M=\rho_0=10$ µm⁻², $\rho_G=0$;
- $\theta_R=\theta$, $G_R$ recomputed;
- $T=T_0$, $V=A=0$;
- work, heat and $E_0$ re-initialised.

The relaxed checkpoint carries no `.mult` side file, so $\lambda$ and $w$ start cold in the first loaded step (a few extra iterations there).

## 6.12 Fast assembly of the staggered fields (version 7.6)

The forms that the step still assembled with FreeFEM are replaced by the plugin or by constant operators; the matrices and vectors are
the same to round-off (coarse run, 10 + 10 steps: every log column identical except `locres` at 10⁻¹⁵, the same Newton iterations).

| Form | Replaced by | When |
|---|---|---|
| `vphA`, `vphR` (phase matrix at φₖ, residual) | `k2dPhAsm`: one element loop, 7-point rule `qf5pT`, values written into a fixed pattern (`A.coef`) | every phase iteration |
| `vphD` (lumped reaction diagonal) | $D=A\mathbf 1$ (the stiffness rows sum to zero) | every phase iteration |
| `vphB` (Newton right-hand side) | $b=A\phi_k-R$ | every phase iteration |
| `vphL` (lumped mass) | built once | — |
| `vph2`, `vgph` (element means of φ², g(φ)) | `k2dPhElem` | every tangent refresh |
| `vDph` (phase dissipation) | `k2dPhElem` | every step |
| `vCurlFp` (GND curl) | two constant P0 → P1 operators | every step |
| `vTr` (heat right-hand side) | $(\rho C/\Delta t)MT_n+B_{01}D/\Delta t$ | every step |

Phase field on the production mesh, serial, 10 steps (48 active-set iterations): 57.2 s → 11.5 s with the same LU solve, 2.6 s with the
projected CG below. Coarse mesh, whole step: the work after the Newton solve falls from 0.53 to 0.28 s per step; the step itself (8.5 s
serial) is dominated by the mechanical linear solve.

**How the fast assembly works.** Nothing about the matrices changes; what changes is who builds them and how often.
1. *Built once per run:* the sparsity pattern of each matrix (taken from one FreeFEM assembly), the map from every element entry to its
   position in the matrix's coefficient array, the element areas and basis gradients, and the quadrature rule (the same 7-point rule
   `qf5pT` that `int2d` uses by default; the 3 edge midpoints for the mechanics). Linear forms with constant coefficients (GND curl, heat
   right-hand side) become constant matrices.
2. *Every call:* one compiled loop over the elements evaluates the fields at the quadrature points once, computes the element matrix and
   residual together, and adds them into the coefficient array (`v[pos] += value`); the FreeFEM matrix receives the values in place
   (`A.coef = v`). No expression is interpreted, no matrix is allocated or sorted, and quantities shared by several forms (φ, T and the
   Arrhenius factor at the quadrature points) are computed once.
3. *Algebra instead of forms:* the active-set diagonal is $A\mathbf 1$ and the Newton right-hand side is $A\phi_k-R$.

The speed-up comes from (2) and (3); the matrices are the FreeFEM ones to round-off, which the periodic comparison verifies.

**Switch.** Fast assembly is on by default (`-fastasm 1`; v2 `-asm 1`). `FASTASM=0` (run.sh), i.e. `-asm 0 -fastasm 0`, assembles every
matrix and vector of the step by the FreeFEM forms again: the phase matrix, residual, diagonal and right-hand side by `vphA`, `vphR`, `vphD`,
`vphB`, the element means, dissipation, GND curl and heat right-hand side by their forms, and the mechanics tangent by the form assembly.
Use it after changing a form until the plugin kernels have been changed to match (the coarse test gives the same log to the printed digits
in both modes; 6.5 against 8.9 s per step serially). The projected-CG phase solve does not depend on it (`-phsolver`).

**Not plug and play.** The fast assembly is written for this discretisation and this model, and the check stops the run when they no
longer match, but it does not adapt. Changes that need code changes in the plugin (and, for the mechanics, in `make_v2.py`):
- *another finite-element space or quadrature:* the kernels hard-code P1 φ and T with the 7-point rule, P2 displacement / P1 θ with the
  edge-midpoint rule, and P0 internal variables; P2 φ, another rule or another element type means new kernels;
- *another material model or energy:* the element formulas (KWC coupling $g(\phi)$, Arrhenius viscosity, stored energy, elastic energy,
  slip law) are duplicated in C++; a change in the `.edp` forms must be made in `plugin/kwc2d.cpp` too (`-fastcheck`, `-adcheck` and
  `ASMCHECK` detect a mismatch, they do not fix it);
- *another mesh:* any triangular mesh is read at start-up and the pattern is rebuilt then, but adaptive remeshing during a run, or a
  restart on a different mesh, needs the set-up to be redone (the plugin keeps one pattern per process);
- *another boundary-condition layout or extra fields:* the patterns and the operators are built for the current dof layout.

## 6.13 Phase-field linear solve: projected CG (`-phsolver cg`, default; MPI `-petscph`)

Each active-set iteration eliminates the active nodes: the system handed to the solver is the free block of $A$ with lumped identity rows on
the active nodes, symmetric positive definite (after Jacobi scaling its spectrum lies in $[0.50, 2.00]$ on the production mesh). It is solved
by conjugate gradients with the Jacobi preconditioner (serial: the loop `phPCG`, stopping at $\|b-Ax\|_\infty\le10^{-13}\|b\|_\infty$; MPI: `-petscph`, default
`-ksp_type cg -ksp_rtol 1e-13 -ksp_max_it 2000 -pc_type jacobi`). For bounds that act on single nodes this is the projected preconditioned CG
with the constraint preconditioner $\begin{pmatrix}\operatorname{diag}A&E^T\\E&0\end{pmatrix}$ of the KKT system with explicit multipliers
$\lambda_{lo}$, $\lambda_{hi}$ (Gould, Hribar and Nocedal 2001): the same iterates. The multipliers, if wanted, are $A\phi-b$ on the active
nodes. Comparison on the production mesh (10 phase steps, Python port matching the solver to $1.3\times10^{-11}$; total / linear-solve
seconds; production bounds, and a stress test with bounds $[0.3, 0.95]$ that makes up to all nodes active):

| Method | $[0, 1-10^{-7}]$ | $[0.3, 0.95]$ |
|---|---|---|
| elimination + CG/Jacobi (= projected CG; adopted) | 1.48 / 0.36 | 1.29 / 0.16 |
| KKT ($\lambda_{lo}$, $\lambda_{hi}$) + projected CG | 1.68 / 0.54 | 1.80 / 0.64 |
| KKT + augmented-Lagrangian Uzawa | 1.49 / 0.41 | 2.41 / 1.28 |
| KKT + MINRES, block-diagonal preconditioner | 1.52 / 0.37 | 2.95 / 1.72 |
| KKT + sparse LU | 9.65 / 8.33 | 5.88 / 4.55 |
| KKT + LDLᵀ (QDLDL) | 6.77 / 5.53 | 10.21 / 8.97 |
| elimination + sparse LU (previous serial solve) | 9.68 / 8.37 | 2.09 / 0.85 |

All reach the same φ (to $5\times10^{-11}$) and the KKT conditions to $2\times10^{-9}$ or better, with non-negative multipliers.
Safeguards: a serial CG solve that does not converge in 2000 iterations is redone by the sparse direct solver (counted); a phase step that
does not converge with CG (in MPI the KSP does not stop the run, the active-set KKT test catches it) is repeated once from $\phi_n$ with
the previous solver (serial direct; MPI `-petscp1`), counted, before the usual stop. Both counts are printed at the end of the run. Tested
serially (coarse mesh, and with CG capped at one iteration to exercise the fallback) and in the 16-rank kt3pcg production runs.


**Check (`-fastcheck` N, default 50; `-fastchecktol` 10⁻⁸).** Each fast assembly is compared with its form on its first call, every N-th
call, and (phase matrix) on the first call in which the Arrhenius floor is reached anywhere and the first in which a node sits on a bound of
φ. The comparison is row by row (element by element for the means), relative to the size of the terms of the row: a global max norm would
hide a wrong entry in an ordinary row behind the rows with $g''\sim10^{14}$ near φ = 1, or behind the terms that cancel in the curl. The
dissipation is compared with its largest value. Round-off: at most 2×10⁻¹² on the coarse test; the tolerance allows for $g''$ amplifying the
round-off of $1-\phi$ by up to $10^7$. A 1% error in one entry of the phase matrix stops the run (measured 1.1×10⁻³); a difference above the
tolerance writes `<out>_FASTCHECK.txt` and stops. The end of the run prints the number of comparisons and the largest difference.

# 8. Energy audit and plate work

**Energy audit.** Every step: $W_{\rm ext}=KE_u+KE_\theta+\Psi_e+\Psi_K+\Psi_s+\int\rho C(T-T_0)-E_0$ ($KE_\theta=0$ in v2); the residual is the log column `audit_residual`. It is a diagnostic of the staggered scheme, not an exact identity. The elastic energy in it (and in `E_elastic`, and $E_0$ at the end of the relaxation and on restart) is evaluated in the committed state. Before 15 November 2026 it was evaluated with the step's plastic increment applied a second time on top of the committed $F_p$ (about 1% of $E_{\rm el}$ in the first loaded steps of the coarse test, and $9\times10^{-4}$ GPa·µm² in $E_0$ there); the trajectory was not affected. Audit columns written before the fix are not comparable with later ones, and a run restarted across the fix keeps its old $E_0$ (stored in the checkpoint), so its audit has a constant offset from then on; a run started from a new relaxation is consistent.

**Plate work.** The reaction force on the constrained dofs is $f_c=-R_{\rm full}$ (including inertia); its work is trapezoidal in time, $\Delta W_{\rm plate}=\tfrac12(f_{n+1}+f_n)\cdot\Delta u_D$. Columns `W_plate` and `audit_full = (audit_residual − resR) + W_plate`. The ledger lives in the side file `<ck>.plate` (tagged `PLATEv2`: step, $W_{\rm plate}$, audit baseline, state, reaction vector, `END`); a restart without a matching `.plate` reports the first step as `nan` and starts a new ledger.

# 9. Checkpoints and restart

- **Atomic generations.** Each checkpoint is an immutable generation `<ck>.g<step>_<k>` plus its side files `.rhoM`, `.gnd`, `.plate` and, in v2, `.mult` ($\lambda$ and the dual flux $w$ per element), validated and published by one rename of `<ck>.manifest`. Only the newest and the previous generation are kept; plain names are hard links to the newest.
- **Restart** reads the generation named by the manifest; a missing generation aborts. A v2 restart with a matching `.mult` continues with the same iteration counts as an uninterrupted run (tested: $U$ to $8\times10^{-15}$); without it $\lambda$ and $w$ start cold.
- **Frequency:** every `-ckevery` 50 steps, plus rolling pre-crash checkpoints every `-ckroll` 20 steps.
- **Recovery** (`recover_ck.sh`): links a rolling checkpoint's generation as a new generation and replaces the manifest.
- **Launcher** (`run.sh`): resolves the committed step from the manifest, trims log rows written after it, refuses to resume while `_NAN.txt`, `_NOCONV.txt`, `_TSTOP.txt` or `STALLED` exist, and refuses a resume with other settings than the run folder's `<tag>.args` (settings files written before November 2026 still contain `-fdk`/`-fdq`; those two are ignored). The fast assembly and `VERBOSE` are outside the settings key.
- Checkpoints are interchangeable between the serial and MPI solvers of the same set-up.

# 10. MPI/PETSc version and hardware

**Generation.** `mpi/make_mpi.py` turns `cosserat_kwc.edp` into `cosserat_kwc_mpi.edp` and `cosserat_kwc_v2.edp` into `cosserat_kwc_v2_mpi.edp` by exact text patches (the v2 file gets in addition the PETSc block solve of the $(U,\lambda)$ system and the parallel `.mult` read and write). FreeFem++-mpi loads plugins from `./mpi/` first, so the build keeps a copy of `kwc2d.so` there.

**Parallel structure.** Overlapping domain decomposition (overlap 1) on 16 ranks; element work on each rank's subdomain; the Newton system, the phase field and the heat equation are PETSc solves; norms, maxima and termination tests are global reductions; rank 0 writes all files on the global mesh in the serial formats. In v2 the multiplier lives on the element space of the decomposition; the blocks $C$, $B$, $E$ are distributed matrices on the $(u,\theta)$ and element numberings, combined into a nested matrix.

| PETSc option | Default | Role |
|---|---|---|
| `-almpetsc` (v2) | FGMRES(200), `fieldsplit` Schur (upper, `selfp`), ASM(overlap 1)/ILU on the $(u,\theta)$ block, Jacobi on the Schur block | $(U,\lambda)$ Newton system |
| `-almfall` (v2) | MUMPS on the converted matrix | redo of a solve that misses $10^3\,$lintol; `-almlin mumps` uses it throughout |
| `-petsc` (penalty, `-almc 0`) | GMRES(200) + ASM(overlap 1)/ILU | $(u,\theta)$ Newton system |

**Verification status.**

- base solver (the set-up used until 15 November): 2 and 4 ranks reproduce the serial Newton history (checkpoints differ by $2\times10^{-9}$); AD and central-difference tangents give identical 16-rank runs.
- v2: 2 ranks reproduce serial (same iterations, $U$ to $10^{-14}$, $\lambda$ and $w$ to $4\times10^{-12}$); FGMRES and MUMPS give the same solution ($4\times10^{-15}$); stop and resume on 2 ranks reproduces the uninterrupted run. 16 ranks have run on the production mesh (a 90° run with the trial value $\eta^*_0=0.1$: 6–9 Newton iterations per step, about 6.9 s per step on an EPYC 9654 node) but have not been compared with serial.

**Timing.** `wall=` in the log is real time and `cpu` the rank-0 CPU time; a ratio well above 1 means ranks are not getting full cores. `VERBOSE=1` prints per step the Newton parts (local update, tangent [element, assembly, matrix hand-over], residual, linear solve) and the whole step (before Newton, Newton with its line search, after Newton), rank 0, CPU seconds.

**Hardware.** Every start of `run.sh` writes a `HOST` line (node, CPU model, CPUs given, physical cores among them, load). Both `.sbatch` files request `--hint=nomultithread`; because a node can still hand out hyperthread siblings, `run.sh` stops with exit code 3 when there are fewer physical cores than ranks (16 ranks on 8 hyperthreaded Skylake cores were several times slower). `bash hw.sh` lists the node types of a partition and estimates start times; `HWCONSTRAINT` (Longleaf: `amd&avx512` for the EPYC 9654 nodes), `HWEXCLUDE` and `HWEXCL=1` are passed to Slurm by the submit scripts.

# 15. The set-up with rotational inertia (`OLD=1`)

`OLD=1` (or `INERTIA=1`) in front of any script runs the same v2 solver with every setting of the default (multiplier with $\mu_c=754$, $\delta=5\times10^{-4}$, numerics, tolerances, safeguards) except the micro-inertia: $j=0.01$ µm² (`-j`, the only difference in the option list). With $j>0$ the $\theta$ equation is hyperbolic, $\rho j\ddot\theta=\operatorname{Div}m+\Pi:(\hat W\bar U)$, and $\theta$ is integrated by Newmark (average acceleration) together with $u$: the $\theta$ mass enters the residual, $c_0\rho jM_\theta$ the tangent, and $KE_\theta$ the energy audit. Tag suffix `_j`, relaxation checkpoint `relax_checkpoint_j.txt`.

Coarse test (400 m/s at 45°, 10 + 10 steps): 5.6 Newton iterations per step (default 6.6), no rejections, largest accepted $|\beta|$ 0.041°, local residual $6\times10^{-15}$; 2 ranks against serial $1.1\times10^{-14}$; $KE_\theta=8.9\times10^{-4}$ against $KE_u=3.0\times10^{-3}$ at 0.1 ns.

History of the name: until the evening of 15 November `OLD=1` was the v2 solver with the Cosserat penalty ($\mu_c=75.4$, `-almc 0`; folders `_old`), and before that the base solver ($\delta=0.005$, exact KWC Hessian, form assembly, capped slip law; folders without a suffix). The scripts resume neither, because the settings key changed.

Resolved command line (`OLD=1`, `ANGLE=45`, 400 m/s, 16 ranks, `TAG=a45_up400ms_j`): the default line of Section 12 with `-j 0.01` in place of `-j 0`.

Seconds per Newton iteration on the production mesh, 2 ranks (restart from the relaxed checkpoint of the base solver): base solver 5.2 (tangent 4.4, linear solve 0.3, local update and residual 0.5); v2 default 2.4 (tangent 0.65, linear solve 1.3, local update and residual 0.5). Under load base-solver runs took about 5 Newton iterations per step and v2 runs 6–8, so a v2 step costs roughly 40% less on equal hardware; this estimate combines 2-rank timings with 16-rank iteration counts and has not been measured on 16 ranks.
